# Ollama AI Debate

Современный веб-интерфейс для организации дебатов между несколькими AI-моделями Ollama.

## 📋 Описание

Приложение позволяет запустить дебаты между несколькими AI-участниками на заданную тему. Каждый участник может:
- Исследовать тему с помощью поиска в интернете (DuckDuckGo)
- Генерировать аватарки через локальную модель стабильной диффузии
- Отвечать на вопросы и аргументировать свою позицию
- Взаимодействовать с другими участниками дебатов

## ✨ Возможности

- **Мульти-модельные дебаты**: До 5 участников одновременно
- **Поиск в интернете**: Интеграция с DuckDuckGo для актуальной информации
- **Генерация аватарок**: Автоматическое создание уникальных изображений для каждого участника
- **Веб-интерфейс**: Современный UI с реальным временем обновления
- **Поддержка прокси**: Работа через SOCKS5 прокси для обхода ограничений
- **Markdown поддержка**: Форматирование ответов с использованием Markdown
- **Модератор**: Возможность вмешательства модератора в ход дебатов

## 🚀 Установка

### Требования
- Python 3.8+
- Ollama сервер (локальный или удалённый)
- Интернет-соединение (для поиска и генерации изображений)

### Шаг 1: Установка зависимостей

```bash
pip install flask ddgs markdown
```

**Опционально** (для работы с прокси):
```bash
pip install PySocks
```

### Шаг 2: Настройка Ollama

Убедитесь, что у вас установлен и запущен [Ollama](https://ollama.ai/):

```bash
# Проверка установки
ollama --version

# Запуск сервера (если не запущен автоматически)
ollama serve

#Pull нужных моделей (примеры)
ollama pull llama3
ollama pull mistral
ollama pull stable-diffusion-xl
```

## 🎮 Использование

### Запуск приложения

```bash
python ollama_debate_web.py
```

После запуска приложение откроет браузер автоматически по адресу `http://localhost:5000`

### Настройки прокси

В начале файла `ollama_debate_web.py` можно настроить использование прокси:

```python
ENABLE_PROXY = True  # Включить/выключить прокси
PROXY_URL = "socks5://127.0.0.1:9050"  # URL прокси
```

### Веб-интерфейс

1. **Тема дебатов**: Введите тему для обсуждения
2. **Участники**: Добавьте участников (имя + модель)
3. **Настройки**: Укажите количество раундов и задержку между ходами
4. **Старт**: Нажмите "Начать дебаты"

Во время дебатов вы можете:
- Просматривать ответы участников в реальном времени
- Видеть аватарки участников
- Добавлять сообщения от модератора
- Останавливать дебаты в любой момент

## 🏗️ Архитектура

### Основные компоненты

- **Flask веб-сервер**: Обрабатывает HTTP запросы и отдаёт веб-интерфейс
- **Debate Engine**: Управляет логикой дебатов и очередностью ходов
- **Search Module**: Поиск информации в интернете через DuckDuckGo
- **Image Generator**: Генерация аватарок через Stable Diffusion
- **Model Manager**: Управление подключением к Ollama моделям

### API Эндпоинты

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/` | GET | Главная страница веб-интерфейса |
| `/api/participants` | GET | Получить список участников |
| `/api/start` | POST | Начать дебаты |
| `/api/reset` | POST | Сбросить текущие дебаты |
| `/api/status` | GET | Получить статус дебатов |
| `/api/moderator/message` | POST | Отправить сообщение от модератора |
| `/api/moderator/finish` | POST | Завершить дебаты |
| `/avatar/<filename>` | GET | Получить аватарку участника |

## ⚙️ Конфигурация

### Переменные окружения

Приложение использует следующие настройки (в начале файла):

```python
OLLAMA_BASE_URL = "http://localhost:11434"  # URL Ollama сервера
SEARCH_ENABLED = True  # Включить поиск в интернете
IMAGE_GENERATION_ENABLED = True  # Включить генерацию изображений
MAX_SEARCH_RESULTS = 5  # Максимальное количество результатов поиска
AVATAR_SIZE = 512  # Размер генерируемых аватарок
```

## 🐛 Решение проблем

### Ошибка подключения к Ollama
```
Connection refused to http://localhost:11434
```
**Решение**: Убедитесь, что Ollama сервер запущен:
```bash
ollama serve
```

### Ошибка импорта ddgs
```
ImportError: No module named 'ddgs'
```
**Решение**: Установите пакет:
```bash
pip install ddgs
```

### Генерация изображений не работает
**Решение**: Убедитесь, что у вас установлена модель Stable Diffusion:
```bash
ollama pull stable-diffusion-xl
```

### Проблемы с поиском
**Решение**: Проверьте интернет-соединение или настройте прокси:
```python
ENABLE_PROXY = True
PROXY_URL = "socks5://127.0.0.1:9050"
```
